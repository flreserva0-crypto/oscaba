# Os Caba — Site para GitHub Pages

Site estático do **Os Caba**, com identidade visual em azul claro e preto.

## Arquivos

- `index.html` — página inicial.
- `regras.html` — central de regras em uma tela/página separada, dividida por categorias.
- `style.css` — identidade visual e responsividade.
- `rules.css` — estilos específicos da central de regras.
- `logo.png` — logo fornecida para o projeto.

## Fontes

O projeto usa `Anton`, `Bebas Neue`, `Permanent Marker` e `Inter`, combinando uma fonte de display pesada com uma fonte manuscrita para aproximar o visual da tipografia da logo.

## GitHub Pages

1. Crie um repositório no GitHub.
2. Envie todos os arquivos deste projeto para a branch `main`.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione `main` e `/ (root)`.
6. Salve e aguarde a publicação.

A central de regras está em `regras.html` e pode ser acessada pelo botão **Regras** no menu.
